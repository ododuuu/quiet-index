# LocalDocSearch

LocalDocSearch is an offline Windows CLI that indexes and searches local Markdown, text, modern Office, and text-based PDF files.

The repository is currently at milestone M0: project foundation and specification.

## Development

```powershell
npm.cmd install
npm.cmd test
npm.cmd start -- --help
```

Read `docs/SPEC.md` for product behavior and `docs/STATUS.md` for the next task.
