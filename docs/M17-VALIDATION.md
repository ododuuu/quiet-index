# M17 0.20.0 驗證

M17 將索引範圍從「內容解析器支援的文件」擴大為「根目錄中所有未被排除的一般檔案」。未知副檔名與無副檔名檔案只保存路徑、檔名、副檔名、大小及修改時間，不讀取正文；搜尋結果顯示 `unsupported` 與僅檔名命中。

## 自動測試

2026-09-19 在 macOS、Node.js 26.7.0 執行 `npm test`：共 135 項，134 通過、0 失敗、1 項 Windows cmd 專屬測試略過。測試涵蓋：

- 未知副檔名與無副檔名進入清冊，解析器只處理支援格式。
- metadata-only 文件的內容不會成為搜尋命中，檔名與任意副檔名 `--type` 可搜尋。
- metadata-only 文件可 `open`／`reveal`，修改只更新 metadata，刪除會移出索引。
- 內建／使用者排除與符號連結仍不進清冊。
- 位於掃描根目錄內的 LocalDocSearch 自有 SQLite／WAL／協調檔會被排除。

`LocalDocSearch-M17-0.20.0.zip` 由打包程序逐檔核對 156 個檔案；另解壓到全新暫存目錄，執行 `npm ci` 後再次得到 134 通過、0 失敗、1 略過。
