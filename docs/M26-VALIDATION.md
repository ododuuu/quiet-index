# M26 0.29.1 驗證

M26 依 SPEC §37 實作根目錄範圍合併。`index` 上層目錄可把涵蓋的既有子根做原子歸屬轉移，保留文件 ID、payload bytes、文件代碼與 `.localdocsearchignore` 作用域；已包含於上層的子目錄只同步該子樹，且不更新上層最後完整同步時間。

0.29.1 修正 Windows 磁碟根目錄輸入：命令列 `"D:\"` 會把尾端反斜線吃掉變成 `D:`，全形 `＼` 也不是分隔符。輸入層將 `D:`、`D:/` 與全形分隔符視為 `D:\`。公司請執行 `index D:/`。

本機自動測試涵蓋：路徑元件／磁碟根／UNC／相似前綴、別名沿用、多子根合併、交易回滾、未變更零解析、不相交根隔離、排除作用域保留與刪除、無法讀取的 ignore 不得當空規則、子樹刪除校正、搜尋 `--root` 子樹篩選、open 文件代碼、CLI 合併／remove／rebuild 提示、watch 停止已合併子根、合併後中止、寫入鎖競爭，離線子樹保留上層文件，以及 `D:`／`D:/`／全形分隔符正規化。M8 原「父子重疊拒絕」改為子樹同步回歸。

2026-09-22 在 Linux 開發沙盒執行 `npm test`：181 項中 178 通過、1 失敗、2 略過。M26 回歸全部通過。失敗項為既有 M7 真實開啟在非 macOS／Windows 平台回報 `ACTION_PLATFORM_UNSUPPORTED`。略過項為 M5 無法讀取目錄及 Windows cmd 專屬 launcher。不得以本沙盒結果取代 macOS 完整回歸或公司 Windows 驗收。

公司 Windows 請以既有 `D:\備份` 索引執行 `index D:/`，確認原文件代碼與搜尋仍可用、其他可讀位置新增、無權限位置有明確診斷且不丟失舊資料、`roots` 無重複、重跑為增量。本機通過不取代公司實機驗收。交付包 `LocalDocSearch-M26-0.29.1.zip`，SHA-256 `add7f3a02441e321fe67ed726c6bd9c9ac989b722d18651bc2b0432433625736`。
