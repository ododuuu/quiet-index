# M9 0.12.0 人選上下文驗證

新增 CLI 分頁選取與 JSON 片段匯出。這是可選的本機上下文準備功能，不是 AI／IDE／MCP 整合，也沒有專用 BU 聊天連接器。

## 自動測試

涵蓋跨頁固定編號、原子切換選取、20 份上限、預選去重、輸入查詢、空集合／取消／EOF／非互動拒絕、確認前無輸出、只匯出選取片段、精確 JSON 預覽、來源／索引變更、刪除、輸出競爭／既有檔案保護、大小限制、終端控制字元跳脫、檔名命中標示與 CLI 參數。

另提供 Windows cmd 入口的測試；macOS 不執行此 Windows 專用案例，不能將略過當成驗證通過。

## 實際終端測試

2026-09-17 macOS PTY，合成 TXT：index→context→選取 1→done→yes；原生 readline 完整預覽後寫入 JSON，重新讀回核對只有一份所選片段，沒有使用公司文件。此為 macOS CLI 行為證據，不是 Windows 互動驗收。

## 集中 Windows 驗收追加項目

```powershell
.\docsearch.cmd context "內文關鍵字" --out "C:\你的可寫目錄\context.json"
```

確認中文顯示、n／p 跨頁選取、v 預覽、done→yes 後檔案建立。再試 q／Ctrl+C 不產生新檔案、既有輸出不覆寫、修改測試來源後拒絕匯出舊片段。匯出 JSON 應只有自己選取的路徑及片段；手動帶入允許通道，不需傳回公司內容。先前 M5～M8 的集中清單仍適用。
