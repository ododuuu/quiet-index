# M5 公司 Windows 驗收

M4 已於 2026-09-16 由使用者回報驗收完成。本表只記錄 M5 新版驗收，目前尚未取得公司 Windows 結果。

已有一項初步 Windows 觀察：使用者回報約 2.83 GB 資料夾的首次 `index` 約 1 分鐘。版本及其他驗收證據尚未確認；內容搜尋不到的檔案已確認是 MVP 不支援的舊版 `.doc`，不是 `.docx` 故障。以下項目仍維持待驗收。

## 環境與準備

- 記錄驗收日期、Windows 版本、CPU、RAM、暫存目錄所在磁碟類型及發佈包 SHA-256。
- 在無管理員權限的 PowerShell 執行 `node --version` 及 `node -p "process.platform + ' ' + process.arch"`，確認目標 Node.js 22.17.0 x64。
- 從新解壓縮目錄依 README 執行 `npm.cmd ci`、`npm.cmd test`；記錄成功、失敗及略過數。權限限制的 POSIX 測試在 Windows 應標示略過；junction 測試應執行。
- 使用自行產生且不含公司資料的中文／含空白路徑；測試索引可使用 `$env:LOCALDOCSEARCH_DATA_DIR = "$env:TEMP\LocalDocSearch-M5-Acceptance"` 隔離。

```powershell
node scripts/demo.mjs
npm.cmd run benchmark -- "docs/benchmark-windows.json" "SSD"
```

`SSD` 請改為實際儲存裝置類型。效能腳本只使用合成資料，會核對全部命中文件、排序與零解析，再保存 JSON 報告。合成 Office 檔案是解析器測試用的最小 XML 套件，實際 Office 開啟及複雜文件情境請另用自建的 Word／Excel／PowerPoint 文件驗證。

回報環境、`npm.cmd test` 結果、未通過項目與效能摘要即可；不要傳送公司文件或包含公司正文的搜尋輸出。只有使用者回報完成後，才將 M5 標示為已通過公司 Windows 驗收。
