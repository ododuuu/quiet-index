## 已完成

- `src/workbench-app.ts` 已改為正式三區自足 GUI：搜尋、分頁、提交快照、跨查詢去重選取、命中片段預覽、臨時文件、狀態頁、抽屜與深淺色／行動底部導覽。命中預覽提供「開啟檔案」及「顯示所在位置」，GUI 搜尋、狀態及 context 不顯示 ISO 時間。
- `src/workbench.ts` 重用既有 search／context／parser 與 `sync()`，提供受 token／Host／Origin 保護的唯讀 `GET /api/index-status`、背景 `POST /api/index` 與 `POST /api/document-action`；後者只接 stable reference 與 `open|reveal`，重用 `actOnDocument`，不接收任意 path。
- 精確預覽只顯示 server 回傳 context 與 bytes；GUI context 省略建立／修改時間，複製不需 Key。GUI 不提供 Provider、Key、問題或外部 AI 回答。
- `src/mcp-tools.ts` 的既有 `indexStatus` 增加逐根文件數、同步摘要與錯誤欄位，未改 MCP 工具的唯讀邊界；GUI 專用 context 可選擇省略時間，CLI／MCP 預設保持不變。
- `test/m35.test.ts` 覆蓋狀態 API、背景更新後搜尋新檔、Host／token、精確 bytes、臨時檔清理及文件操作 API 輸入拒絕。
- `src/tui.ts` 已改為單欄時間序 transcript 與固定 composer；最多 12 筆 workflow 只存在本次 `runTui()`。成功搜尋、選取與 context 使用真實 total／passages／bytes，索引變更即清除；搜尋、context、open／reveal、鍵盤及 lifecycle 服務未改。
- `docs/design/SEEKAH-TUI.md` 與 `seekah-tui.html` 已同步 120×40／80×24 資訊架構；HTML 明示示範資料且不連接索引。
- `docs/USER-GUIDE.md`：使用者可依單一路徑完成安裝、首次索引、GUI 搜尋／開啟／上下文複製、TUI／CLI 與常見問題；README 與 CURRENT 已連結。
- GUI 修正：上下文面板 × 可在所有尺寸關閉，右上「已選 N」重新開啟；啟動後背景同步已登錄根目錄並顯示檢查進度，尚無索引時由使用者在 UI 輸入第一個根目錄。`seekah-ui.cmd`／`seekah-ui.command` 透過 `scripts/launch-ui.mjs` 雙擊啟動：首次自動 `npm ci` 並顯示相依進度，完成後再開工作台。
- GUI 精確上下文現只提供本機預覽／複製，隱藏 Provider、model、Key、外傳同意及 AI 回答；CLI／MCP 不變。
