## 實作順序與測試

1. **scope-aware deletion**：scanner 目前只有 root-global complete，任何 scan error 都使 sync 跳過 removeMissing。以最小不可確認 subtree／file scope 保護既有資料；正常 sibling 的缺失文件可刪。先寫測試：sibling A 拒絕存取，B 刪文件→A 保留、B 移除；root failure→整根保留；單檔 read/stat failure、parser error、prefix collision、重建和局部更新不誤刪。src/scanner.ts、sync.ts、store.ts；實際規則依 §45.3。
2. **Windows 系統目錄**：目前只有提示，沒有 built-in exclusion。scanner／watch／local update 共用判定，只匹配 volume／UNC root 直接子目錄精確名稱，case-insensitive。測相似名、巢狀同名、直接登錄系統目錄、歷史已索引項目清理、非 Windows。不可修改 .localdocsearchignore，不可刪除來源文件。
3. **profile UX**：重現 CMD 傳入 PowerShell 字面變數，顯示可理解的 resolved parent／錯誤碼及 CMD／PowerShell 範例；不自行展開變數、不建父目錄、不覆寫輸出。測 ENOENT、權限、EEXIST、正確路徑與索引未寫入。
4. **完整落地核准 TUI**：目前 readline question() 只收命令。拆出 key decoder／純狀態機／render／terminal lifecycle，按設計做首頁、結果、preview、已選清單、context 確認、命令與真實 status。↑↓、Space、Enter、PgUp／PgDn、Esc／←、Tab／Shift+Tab、/、q／Ctrl+C 不可缺。不是把 /select 或 /next 包成新提示。實作順序先 reducer 測試再 render fixture 再 PTY；詳見設計文件。
5. **交付**：完整 npm test、npm run package（逐檔核對），提供 0.36.1-VALIDATION.md、實際終端畫面、公司普通使用者人工測試清單。完成才同步 package／lockfile 至 0.36.1；更新 README、STATUS、NEXT-TODO、DECISIONS 與本資料夾。若未完成，保留 0.36.0 並清楚報告剩餘項目。

## 更名相容性邊界

- **不得搬移／重建索引**：Windows LOCALAPPDATA/LocalDocSearch/index.db、其他平台原有路徑、LOCALDOCSEARCH_DATA_DIR 不變。
- .localdocsearchignore、.localdocsearch、SQLite schema／parser version、IPC single-instance pipe、MCP registration／resource URI、X-LocalDocSearch-Token 不改。
- docsearch alias 與 seekah 指向同一 CLI，不能啟動兩套 daemon 或建立第二個資料庫。
- 新壓縮包 Seekah-VERSION.zip，內層 Seekah/，同時含兩個 CMD launcher。舊檔名 checksum 與版本歷史不改寫。
- 導出的 context 標題改成 Seekah，但格式、安全確認、來源驗證、字節限額、明確 AI 同意邊界不變。
