## 公司 Windows 待驗

這不是公司 Windows 驗收。使用普通使用者帳號及無機密測試樹：

1. sibling A 設為不可讀，刪除 sibling B 文件；index 後 A 舊紀錄保留、B 移除。另測 root 整體不可讀。
2. 核對 drive／UNC root 兩個系統目錄被排除，相似名與普通巢狀同名仍可索引；不要對公司整庫做破壞性 deletion 實驗。
3. 在 CMD／PowerShell 分別測成功新 profile、不存在父目錄、權限拒絕及既有檔案。
4. 在 Windows Terminal 80×24／120×40 測中文搜尋、跨頁選取、preview、Esc、Tab、q、Ctrl+C、resize、context 取消與逐字 `yes`。
5. 不上傳公司文件、索引、profile 或敏感 verbose log；不刪 SQLite／WAL／journal，不要求 rebuild。
