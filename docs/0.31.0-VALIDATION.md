# 0.31.0 驗證

0.31.0 依 SPEC §39／D047 實作背景自動更新。公開命令為 `autoupdate start|status|stop`。前景 `watch` 改用同一局部更新引擎與持續更新 lease；檔案事件只更新該檔或最小子樹，不再每個事件全根 `sync()`。背景程序以 detached Node.js 執行，不安裝 Windows Service，不做登入／開機自啟。重開機後 status 必須顯示已停止。

編碼政策維持 0.30.0：BOM／XML 宣告優先，無訊號時嚴格 UTF-8，失敗才嚴格 Big5。本版不改索引正文 schema，0.30.0 索引可直接使用。

## 本機自動測試

2026-09-22 Linux 開發沙盒 `npm test`：213 項中 210 通過、1 失敗、2 略過。新增 16 項 0.31.0 測試涵蓋：

- 局部新增／修改／刪除／改名／子樹，且不更新最後完整同步時間
- 父目錄不可讀時保留舊索引
- 解析前後檔案變動依 1／2／5／15／30 秒退避五次後保留舊索引
- writer lock 1／2／5／10／30 秒退避
- 檔案事件不呼叫全根 sync；未知 filename 改完整校正
- `autoupdate` 參數、未啟動、search／status 不暗中啟動
- 日誌輪替約 10 MiB、token 不進日誌或命令列
- detached start、中文／空白／括號路徑、重複 start、設定不同拒絕、status、stop
- 殘留死 PID 可取代；前景 watch 與 autoupdate 互斥

失敗項為既有 M7 真實開啟在非 darwin／win32 回報 `ACTION_PLATFORM_UNSUPPORTED`。略過項為 M5 無法讀取目錄（root）及 Windows cmd launcher。不得把此沙盒結果寫成 macOS 全套通過或公司 Windows 驗收。

## 公司 Windows 人工驗收

請在公司電腦對現有索引執行，不要 rebuild、不要刪除資料庫：

1. `docsearch autoupdate start` → 關閉原 CMD → 新增／修改／改名／刪除文件 → 另一 CMD `search` 驗證。
2. 新增根目錄並合併上層 → `autoupdate status` 顯示新根監看。
3. 另開 CMD 執行手動 `index`，確認背景退避且不互相殺死。
4. `autoupdate stop` 後 status 為未啟動；重開機後 status 必須誠實顯示已停止，再 start 補齊停機期間變動。
5. 只回報行為與錯誤碼，不要上傳公司文件內容。
