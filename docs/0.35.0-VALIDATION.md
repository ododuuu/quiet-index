## 已證明的行為

- server 只監聽 `127.0.0.1`，每次啟動使用 URL fragment token；API 同時檢查 Host、token，非 GET 再檢查 Origin。
- HTML 自足且 CSP 預設全拒；沒有外部 script／style、`innerHTML`、cookie、`localStorage` 或 `sessionStorage`。
- 拖曳文件沿用正式 parser；暫存原檔以 mode 0600 寫入權限受限目錄，解析後立即刪除，close 時再遞迴清理 session 目錄。
- 工作台重用既有索引搜尋與選取 context；索引與拖曳合計最多 20 份，合併輸出最高 256 KiB。
- API Key 可來自 `OPENAI_API_KEY`／`XAI_API_KEY` 或 UI 本次輸入；狀態只回報是否設定及來源，不回傳值。session Key 在 close 時清除。
- 遠端呼叫固定為 OpenAI／xAI Responses endpoint；OpenAI 設 `store: false`。送出前的 HMAC 綁定 provider、model、問題與實際 context，修改問題的舊 preview 會在呼叫假 Provider 前被拒絕。

## 尚未驗收

- 公司 Windows 的瀏覽器啟動、中文路徑拖曳、防毒／端點防護、Ctrl+C 清理及長時間使用。
- 真實 OpenAI／xAI API 帳務、模型權限、代理伺服器、速率限制及供應商回應差異。
- 公司政策是否允許把任何選定片段送往外部 API；不允許時只能使用本機搜尋、預覽、複製、TUI 或 MCP 的獲准路徑。
- ChatGPT Plus／Pro、SuperGrok／X Premium 訂閱不能當作 API 額度；本版沒有也不假裝提供消費訂閱登入。

## 公司 Windows 建議驗證

1. `npm.cmd ci`、`npm.cmd test`，記錄 Node 與測試統計，不提交公司路徑或內容。
2. `node dist/src/cli.js ui --no-open`，確認 URL 是 `127.0.0.1` 且帶 `#token`；另開沒有 token 的 URL應看不到 API 資料。
3. 只拖入獲准的代表檔，確認解析狀態、移除、預覽與關閉後臨時目錄清理；不要先用機密文件測外部 API。
4. 依公司政策決定是否允許真實 Provider。允許時先用無機密合成文字與低權限／低額度 API Key，核對 model、帳務與回答；不允許時略過，不繞過控管。
5. PDF／PPTX／XLS 真實錯誤仍依 `COMPANY-WINDOWS-DIAGNOSTICS.md` 在公司電腦本機處理，不上傳原檔。
