# M12 0.15.0 驗證

## 行為

`watch --rescan 300000` 為預設行為，週期從每次同步完成後起算；0 關閉，其他允許 1000～3600000 ms。只掃原本選定的登錄根目錄，沿用大小／mtime 增量比對與既有排除規則。

原生監看失敗會降級定期掃描，每輪重新嘗試監看。根目錄離線保留內容與最後完整同步時間，記錄失敗；恢復後重試並更新。停止時清除所有計時器、關閉監看並等待同步結束。

- 慢同步不累積校正 timer，停止等待寫入完成。

- 事件與校正重疊合併、不並行解析同一根。

計時器／監看失效採注入以穩定重現；真實 macOS 監看另由 M11 原生 fs.watch 測試覆蓋。不是 Windows／網路磁碟驗證。

## Windows 集中驗收

1. 在測試資料夾 index 後執行 `docsearch.cmd watch --rescan 1000`。
2. 另開終端修改、新增、刪除文件，search 應反映新內容。
3. 測試目錄暫時移走，status 應標示最近同步失敗，舊結果仍存在；還原後應恢復內容更新。
4. Ctrl+C 後可重新開啟索引；另測 `--rescan 0` 舊模式。

限制：校正間隔不含掃描耗時，網路存取延遲不保證；跨程序同步／roots remove 尚無排他鎖，先停止 watch 再移除。公司 Windows 結果尚待回報。
