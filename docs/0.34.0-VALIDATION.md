# 0.34.0 MCP App 搜尋工作台與本機接入驗證

日期：2026-09-23

## 已完成

- MCP server 發布 `ui://localdocsearch/search-context-v1.html`，MIME 為 `text/html;profile=mcp-app`；只有 `open_search_app` 綁定 UI，三個資料工具保持 headless 可用。
- 自足工作台透過 MCP Apps bridge 呼叫 `search_documents`／`prepare_context`，支援片語／全部詞、每頁 20 筆、前後頁、跨頁勾選最多 20 份及清空選取。
- 「加入 AI 上下文」先重新驗證已選文件，再呼叫 `ui/update-model-context`；只有使用者另填問題並按「加入並送出問題」才呼叫 `ui/message`。
- UI 不含外部 URL、CDN、fetch、WebSocket、`innerHTML` 或 localhost port；server 回傳路徑與片段只以 DOM 文字 API 顯示。
- `docsearch setup codex [--dry-run]` 以 argv 呼叫官方 Codex CLI，不經 shell。相同設定冪等；同名異設定拒絕覆寫；dry-run 不執行任何外部命令。
- `docsearch doctor` 只讀檢查 Node.js 22.17.0、CLI build、索引格式與 MCP／App 註冊，不建立索引、不升級 schema、不修改 Codex 設定。

## 公司 Windows／真實 Host 待驗證

1. 解壓後以 Node.js 22.17.0 執行 `npm.cmd ci`、`npm.cmd test`；不要把上述 Mac 結果寫成 Windows 通過。
2. 執行 `node dist/src/cli.js doctor`，保存通過／失敗項目但不貼公司路徑或內容；索引需要升級時先執行普通 `index`。
3. 執行 `node dist/src/cli.js setup codex --dry-run` 核對 node、CLI 絕對路徑；確認後再執行 `node dist/src/cli.js setup codex`。以 `codex mcp list` 或 Host 的 `/mcp` 核對。
4. 請 Host 呼叫 `open_search_app`。若 Host 不顯示嵌入 UI，記錄 Host／版本與「headless 可用、UI 未支援」；不得把工具可呼叫冒充按鈕已驗收。
5. 在 UI 搜尋獲准的非機密代表文字，跨頁勾選兩份；核對切換片語／全部詞會清空選取、超過 20 份被拒絕、未按按鈕不會加入上下文。
6. 按「加入 AI 上下文」後另發一則問題，核對只引用已選片段；再測「加入並送出問題」。來源修改後應拒絕過期選取。
7. 不提交公司原文、片段、索引、畫面或完整路徑。真實 PDF／PPTX／XLS 問題仍只依 `COMPANY-WINDOWS-DIAGNOSTICS.md` 在公司電腦處理。

## 已知邊界

- MCP Apps 是 Host 可選能力；0.34.0 能發布標準 resource，不保證每個 Codex／ChatGPT／第三方版本都會渲染。headless tools 與 TUI 是正式備援，不是 UI 驗收證據。
- ChatGPT 網頁不讀本機 Codex `config.toml`。本版沒有遠端 MCP、tunnel 或 public plugin，不改變公司內容能否交給特定 AI 的政策。
- `ui/update-model-context` 更新由 Host 管理，Host 可以拒絕或延後；介面會顯示錯誤，不繞過 Host 權限。
