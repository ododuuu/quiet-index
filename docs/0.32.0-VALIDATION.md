## 公司 Windows 人工驗收

使用非機密或已獲准的代表檔；文件不得上傳：

```powershell
npm.cmd ci
npm.cmd test
node dist/src/cli.js index "D:/允許索引的測試資料"
node dist/src/cli.js search "XLSM測試字" --type xlsm
node dist/src/cli.js search "ODT測試字" --type odt
node dist/src/cli.js search "RTF測試字" --type rtf
node dist/src/cli.js search "CSV測試字" --type csv
node dist/src/cli.js tui
```

TUI 中驗證直接搜尋、`/next`、`/refine`、`/back`、`/open 1`、`/reveal 1`、`/status`、`/roots`、`/quit`。只回報是否命中、位置、狀態、錯誤碼與介面是否正常還原，不貼公司正文。

公司真實 PDF／PPTX／XLS 錯誤另依 `docs/COMPANY-WINDOWS-DIAGNOSTICS.md` 處理，不混入本驗收，也不阻塞 0.32.0 本機實作。
