## 瀏覽器驗收

使用隔離合成索引 `/tmp/seekah-gui-fixture`（24 份 TXT）及獨立 `LOCALDOCSEARCH_DATA_DIR=/tmp/seekah-gui-data`，未使用公司文件或真實 Provider：

1. 以 `node dist/src/cli.js ui --no-open` 啟動正式入口，確認服務只輸出 `127.0.0.1` URL。
2. Chromium 1280×800：搜尋 `gui-search-needle` 得到 24 筆，頁面顯示 `1–20 / 24`，實際結果 20 筆，無水平溢位。
3. 勾選文件後開啟「檢查精確上下文」；可見內容來自 server `/api/preview`，包含實際命中片段與 server bytes，狀態顯示主要路由。
4. 使用瀏覽器剪貼簿讀回值，與可見完整 server context 逐字一致；未設定 Key 也可複製。
5. 進入「索引狀態」：顯示實際 24 份文件、實際根目錄與歷史同步時間；狀態頁沒有觸發掃描。
6. Chromium 390×844：底部四項導覽可見、上下文仍可開啟、設定入口在頂列、`documentElement.scrollWidth` 未超過 viewport；設定對話框可開啟並暴露 Provider、model、Key 欄位。
7. Provider 使用測試中的注入 fake fetch；未發出付費 API 請求。自動路由 quota fallback 與重複 ask 由 `m35` 回歸測試驗證。

截圖工具在目前 headless Chromium 執行環境逾時，因此本文件不以未成功取得的截圖冒充畫面檔；上述畫面與互動均由正式入口、正式 API 與瀏覽器 DOM／無障礙樹觀察完成。
