# Seekah 0.36.2 驗證紀錄

日期：2026-09-24。版本：0.36.2。範圍：SPEC §47／D059 GUI 與 SPEC §45.8／D063 TUI；不包含 0.37.0。

## 實作範圍

- `src/workbench-app.ts`：正式三區 GUI，不使用設計稿示範陣列；左導覽、中央搜尋、右上下文、行動底部導覽、抽屜與預覽對話框共用真實 API。命中預覽可要求開啟檔案或顯示所在位置，搜尋、狀態與 context 不顯示 ISO 時間；上下文面板可在所有尺寸關閉／重開。
- `src/workbench.ts`：保留 loopback、fragment token、自訂 header、Host／Origin 驗證、nonce CSP、臨時檔清理與文件操作 stable reference；提供唯讀 `GET /api/index-status`、背景 `POST /api/index` 與 `POST /api/document-action`。索引重用既有 `sync()`。
- `src/mcp-tools.ts`：既有 `indexStatus` 增加逐根文件數、同步摘要與錯誤欄位，仍為唯讀；GUI 的 context 可省略時間，CLI／MCP 預設不變。
- `seekah-ui.cmd`／`seekah-ui.command`：直接開啟 GUI；首次 `npm ci` 後不需為每次工作台啟動重跑安裝。
- `test/m35.test.ts`：覆蓋狀態 API、背景更新後可搜尋新檔、文件操作 API 的非法／過期輸入拒絕、真實預覽 bytes、無 timestamp context、Host／token 與臨時檔清理。
- `docs/USER-GUIDE.md`：從首次啟動到 GUI、TUI、CLI、複製與排錯的操作手冊。
- `src/tui.ts`：單欄 transcript、session-local 12 筆 workflow、固定 composer；鍵盤與 lifecycle 未改。

## 瀏覽器驗收

使用隔離合成索引與獨立 `LOCALDOCSEARCH_DATA_DIR`，未使用公司文件：

1. 以 `node dist/src/cli.js ui --no-open` 啟動正式入口，確認服務只輸出 `127.0.0.1` URL。
2. Chromium 1280×900：尚無索引時「索引狀態」顯示第一個根目錄輸入與「開始建立索引」。
3. 輸入隔離根目錄後，工作台背景建立索引；畫面顯示該根的 1 份文件與「索引已更新。」。
4. 新增 `fresh.txt` 後按「更新索引」，完成後搜尋 `fresh GUI refresh needle` 得到實際命中。
5. 按右側上下文面板 × 後面板隱藏、`scrollWidth=1280`；按右上「已選 0」可重新開啟。未見 Provider、API Key、問題、同意或 AI 送出控制項。
