## 現在不能宣稱的結論

- 「新版已通過公司 Windows 驗收」：沒有使用者回報。
- 「每天用得順」：M14 已有合成資料的真實互動操作，但尚未有使用者日常資料與持續使用回饋。
- 「所有舊文件都能全文搜尋」：unsupported／encrypted／no_text／too_large 仍有明確界線；未知副檔名略過。
- 「所有 AI／網頁都能讀本機索引」：0.33.0 是本機 stdio MCP，只供已註冊且相容的本機 Host；ChatGPT 網頁不會自動讀取。
