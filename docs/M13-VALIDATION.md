# M13 0.16.0 驗證

## 範圍

以索引旁的 SQLite 交易協調檔序列化同步、重建和移除根目錄。SQLite BEGIN IMMEDIATE 的官方依據見 D027。協調檔不保存文件文字，保留檔案；釋放的是交易鎖。

## 自動測試

`test/m13.test.ts` 覆蓋：

- 獨立子程序持鎖，sync／rebuild／roots remove 明確拒絕；CLI 退出 3，主索引報告不被忙碌覆蓋。
- 持鎖期間，另一 CLI 程序 search／status 可用。
- 強制終止持鎖子程序後，不刪協調檔即可重新同步與搜尋新內容。
- 掃描例外釋放鎖、釋放函式可重複呼叫、不同索引互不阻擋。
- 符號連結別名共用主索引實際路徑的鎖（Windows 因建立 symlink 可能需額外權限而略過）。
- 鎖覆蓋掃描開始到最後提交，同步中不能移除根目錄。
- 僅限登錄根的同步不能復活已移除根；明確 index 仍可新增。
- watch 即使 rescan=0 也會在忙碌後重試，不覆寫同步摘要。

本機測試不代表 Windows 鎖、終止程序或公司磁碟政策已驗收。Windows 的 cmd 與 symlink 平台測試略過條件分別列於各測試，不混為已通過。

## 操作限制

只有採本版寫入協定的程序互斥。不要混用舊版，也不要手動移除執行中的協調檔。索引存放本機磁碟；來源可在可讀網路目錄。搜尋讀取目前已提交資料，不是整批同步的固定快照。
